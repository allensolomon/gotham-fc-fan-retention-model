# NJ/NY Gotham FC: Fan Retention & Yield Optimization

### https://public.tableau.com/app/profile/allen.solomon/viz/NJNYGOTHAMFCFANRETENTIONYIELDOPTIMIZATIONMODEL/Dashboard1

## Project Overview
This model identifies a **$269k+ incremental revenue opportunity** for Gotham FC by analyzing fan churn. Using attendance data from **FBref.com**, the model simulates how a 10% lift in retention for high-acquisition Sunday fixtures impacts the bottom line.

## Key Features
* **Revenue Sensitivity Tool:** Allows users to adjust retention targets to see real-time ROI impact.
* **Fan Segmentation:** Categorizes attendance into "First-Time" vs. "Repeat" fans.
* **Volatility Analysis:** Visualizes seasonal attendance trends to identify peak acquisition windows.

## Tech Stack
* **Tableau:** Data visualization and dashboard interactivity.
* **Excel:** Data cleaning and probabilistic attribution modeling.
* **Data Source:** FBref (2025-2026 Home Match Datasets).
